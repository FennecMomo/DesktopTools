# DesktopTools 自由窗口

一个常驻 Windows 系统托盘、可管理多个半透明置顶浮窗的桌面工具。

## 使用

Windows 可直接双击 `dist/DesktopTools.exe` 启动，无需安装 Python。浏览器用途还需要系统安装 [Microsoft Edge WebView2 Runtime](https://developer.microsoft.com/en-us/microsoft-edge/webview2/)。使用源码时，先运行 `python -m pip install -r requirements.txt`，然后双击 `start_overlay.cmd` 或直接双击 `overlay_window.pyw`。

程序启动后会在任务栏右下角通知区域显示托盘图标。右键托盘图标可选择：

DesktopTools 只允许一个后台实例运行。已经运行时再次双击 EXE，不会再创建第二套托盘与自由窗口；程序会切换到现有实例，并恢复被快捷隐藏的窗口。如果此前已关闭全部自由窗口，则会在现有实例中添加一个窗口。

- **添加自由窗口**：绿色加号，在当前后台进程中创建一个新的独立窗口实例。
- **快速收集**：在鼠标附近打开输入框，可把复制的文字一键加入待办或追加到便签；也可按全局快捷键 `Ctrl+Alt+D` 唤出。若快捷键被其他程序占用，仍可从托盘菜单打开。
- **设置**：蓝色齿轮，统一调整全部实例的透明度、边缘收起开关、无背景显示和展开边距，也可设置当前用户开机启动。
- **检查更新**：从 GitHub 的版本索引检查并下载最新 EXE。
- **退出**：红色电源键，关闭全部自由窗口并结束后台程序。

双击托盘图标也可以快速添加一个自由窗口。

- 拖动顶部标题栏可移动窗口。
- 将标题栏拖到任意显示器边缘并松开，窗口会动画收起为置顶小球。
- 单击小球即可恢复；窗口会完整回到当前显示器内，并与停靠边保持 10px 间距。
- 拖动右下角可调整窗口大小。
- 点击“锁定”后，正文仍保持可见，但背景、标题和其他控件会隐藏；鼠标操作穿透正文到后方应用，悬浮也不会重新显示背景。
- 锁定时只有独立置顶的解锁图标可点击，点击后在原位恢复完整窗口。
- 点击窗口右上角“×”只关闭当前自由窗口实例。
- 默认按 `Ctrl+K` 可暂时隐藏全部自由窗口、锁定/解锁按钮、悬浮球及球旁的快捷图标；再次按下按原来的普通、锁定或收起状态恢复。设置和快速收集窗口若正打开，也会一起暂时隐藏，托盘仍保留；也可从托盘右键菜单选择“隐藏/显示全部窗口”。适合截图前清空画面；隐藏状态不会写入存档，重新启动后正常显示。
- 开启设置中的“无背景”后，鼠标不在窗口上时只显示白字黑描边的正文，背景、标题、按钮和缩放手柄全部隐藏；鼠标移入窗口范围内会自动恢复完整界面。锁定时也使用同样的正文样式，在深色和浅色环境下都更容易辨认。

标题栏的“用途”按钮可为当前自由窗口选择七种模式，菜单末尾还可选择“绑定任务编号…”：

- **便签**：随手记录临时文字，适合对照资料或整理思路。
- **待办**：添加事项，双击或点击“完成 / 撤销”切换状态；选中后可编辑或删除。编辑时在上方输入框修改，再按回车或点“保存修改”；“取消”会放弃改动。列表中也可按 F2 编辑、按 Delete 删除。
- **任务胶囊**：在待办中选中一项，点击“开始专注”，会另开一个绑定同一任务编号的胶囊窗口，原待办窗口保留。胶囊可暂停、继续、重来，时间结束会发出提醒，再点“完成任务”可同步勾选待办。锁定后任务和倒计时仍可见，鼠标可穿透正文。重新启动后从剩余时间暂停，手动继续即可。
- **倒计时**：设置 1–180 分钟，可开始、暂停、继续和重置。
- **时钟**：始终置顶显示当前时间和日期。
- **快捷按键**：把常用操作做成按钮。“切换窗口”按 Alt+Tab 的最近使用顺序依次切换：每次点击激活浮窗下面的下一个窗口，最小化的窗口会自动恢复，点完一圈回到最近使用的那个；浮窗保持置顶，被切换的窗口显示在它后面。窗口收起为小球后，快捷按钮会变成比小球略小的小图标，从球的正下方依次向下排列（下方空间不足时改排在球上方），点一下即可执行。后续会继续加入更多快捷按钮。
- **浏览器**：在自由窗口中打开网页，支持输入网址或搜索词，以及后退、前进和刷新。首次切换会把过小的窗口扩到适合浏览的大小，之后仍可自行缩放。每个窗口单独记住最后访问的网址；浏览器的 Cookie 和缓存保存在 `%LOCALAPPDATA%\DesktopTools\browser`。网页与程序之间不开放调用接口，下载默认禁用。锁定或无背景显示时会隐藏网页控件，只显示当前网址，以保证鼠标穿透；解锁后可继续浏览。部分网站可能限制内嵌浏览器访问。

窗口编号与任务编号相互独立。新窗口没有指定绑定时，默认绑定与窗口编号相同的任务；通过“绑定任务编号…”可改绑已有任务，输入尚不存在的编号则新建该任务。窗口编号不会因改绑而变化。同一任务编号的多个窗口共享便签、待办和计时：例如一个显示待办、一个显示任务胶囊，还可有一个显示倒计时。任务编号显示在窗口正文的状态栏中。切换窗口用途不清除任务内容；关闭窗口也不删除任务。如果该任务的所有窗口都关闭，运行中的计时会暂停。

窗口的用途、位置、大小、锁定和收起状态、浏览器网址，与各任务的便签文字、待办事项、计时设定及胶囊进度都会自动保存。退出程序后再次启动，会恢复退出时仍打开的窗口；点“×”关闭的窗口也会保留存档，下次从托盘“添加自由窗口”会优先恢复最近关闭的窗口。普通倒计时的运行进度不会跨重启延续，恢复后从设定时长重新开始。

快速收集仅在打开时读取剪贴板里的文字作为预填内容；只有点击“加入待办”或“追加到便签”才会保存。优先写入最近的同类窗口（任务胶囊也算待办窗口），没有同类窗口时会新建一个。图片内容暂不支持，见 [待办计划](TODO.md)。

在“无背景”或锁定状态下，空便签也会显示“空便签”提示，避免窗口看起来完全消失。

边缘收起支持多显示器，也支持位于主显示器左侧或上方的负坐标屏幕。

关闭最后一个自由窗口后，程序仍会在系统托盘中运行。只有托盘菜单中的“退出”会彻底结束程序。

全局设置保存在 `%LOCALAPPDATA%\DesktopTools\settings.json`，窗口与任务存档分别保存在同目录 `windows.json` 的 `windows` 和 `tasks` 部分；旧版逐窗口内容会自动迁移。修改后会自动写入磁盘，关闭窗口和退出程序时也会立即保存；写入时使用临时文件原子替换，避免中断损坏原文件。窗口以小球收起时的状态和位置、锁定状态同样会恢复；恢复锁定窗口时，独立解锁图标仍可点击。便签与待办内容是本机明文文件，请勿在其中记录密码等敏感信息。

“开机启动”默认关闭。开启后会在当前用户的 Windows `Run` 注册表项中记录程序路径，无需管理员权限；关闭或恢复默认设置会移除此项。建议先把 EXE 放在固定位置再开启；如果之后移动了 EXE，从新位置手动运行一次会更新已启用的启动项。

设置中的“快捷隐藏快捷键”可输入 `Ctrl+K`、`Ctrl+Shift+H` 等组合，点击“应用”生效并自动保存。主键支持字母、数字和 F1–F12，至少包含 Ctrl 或 Alt；`Ctrl+Alt+D` 留给快速收集。如果组合键被其他程序占用，设置会提示并保留此前可用的组合键。

设置窗口也有“检查更新”按钮和“自动更新”开关。自动更新默认关闭；开启后，打包版 EXE 每次启动会在后台检查一次。新版来自仓库 `main/dist/update.json` 指向的 `dist/DesktopTools.exe`，下载后会校验文件大小和 SHA-256；校验通过才会准备安装。手动检查时可选择立即退出、安装并重新启动；否则会在下次正常退出程序后安装，下次启动即为新版。更新程序本身不使用本机的 Git 凭据，也不会覆盖便签、待办及设置存档。源码运行时不会自我更新，请改用 EXE 测试此功能。

## 版本与发布

版本号采用 `A.B.C`，首个版本为 `1.0.0`。今后**每次提交**按变更类型递增对应数字：系统框架或不兼容架构调整递增 `A`，新增或扩展功能模块递增 `B`，修复与一般修改（包括文档、界面细节）递增 `C`；递增较高位时，右侧数字归零。同一次提交涉及多类变更时取最高级别，版本号按提交次数而非功能数量计算。提交时同步修改 `overlay_window.pyw` 中的 `APP_VERSION`，用 `python build_release.py` 重新打包并生成匹配的 `dist/update.json`，把源码、EXE 和索引一起提交。提交日志必须使用中文，带上版本号并写明本次变更内容，例如 `功能版本 2.2.0：新增浏览器与快捷隐藏功能`。用户只说“推送”时，执行提交和推送，不自动发布 Release。推送 `main` 后，用户端才会看见新版本。仅在明确要求发布版本时，再建立同号的附注标签 `vA.B.C` 并推送；仓库的 GitHub Actions 会核对版本、大小及 SHA-256，再将 EXE 和索引作为 GitHub Release 附件发布，标签说明会作为发布说明。GitHub Actions 使用 GitHub 自带的临时令牌，本机无需保存 GitHub API 令牌。

除浏览器控件依赖 `tkwry` 和系统 WebView2 Runtime 外，程序主体使用 Python 标准库；托盘菜单图标由程序直接绘制，无需额外图片资源。`tkwry` 会被打包进 EXE，WebView2 Runtime 由 Windows 系统提供或单独安装。
