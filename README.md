# DesktopTools 自由窗口

一个 Windows 半透明置顶浮窗。

## 使用

双击 `start_overlay.cmd` 启动，也可以直接双击 `overlay_window.pyw`。

- 拖动顶部标题栏可移动窗口。
- 将标题栏拖到任意显示器边缘并松开，窗口会动画收起为置顶小球。
- 单击小球即可恢复；窗口会完整回到当前显示器内，并与停靠边保持 10px 间距。
- 拖动右下角可调整窗口大小。
- 点击“锁定”后，整个主窗口会让鼠标操作穿透到后方应用。
- 锁定状态下只有“解锁”按钮响应点击。
- 点击右上角“×”退出软件。

边缘收起支持多显示器，也支持位于主显示器左侧或上方的负坐标屏幕。

程序只使用 Python 标准库，不安装依赖，也不会保存窗口位置或其他运行状态。
